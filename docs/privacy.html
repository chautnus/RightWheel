Privacy Policy — RightWheel

Effective Date: November 25, 2026

1. Overview & Zero Data Collection

RightWheel is an offline-first desktop productivity utility for Windows 10 and Windows 11. We respect your privacy: the application does NOT collect, store, transmit, sell, or share any personal information, telemetry, analytics, or mouse/keyboard logs to any external server.

2. Local Mouse Input & Desktop Permissions (runFullTrust)

To detect right-click scroll combinations, draw gestures, and execute user-configured shortcuts across applications, RightWheel uses Windows Desktop Full-Trust capabilities (runFullTrust) and standard Win32 input hooks (WH_MOUSE_LL):

  • Mouse button state, wheel delta, and gesture coordinates are processed strictly in-memory on your local device in real time and are never recorded or uploaded.
  • Active window titles/process names are inspected locally in memory solely to apply per-application shortcut profiles configured by you.
  • All user configurations and profiles remain locally on your device under %APPDATA%\RightWheel\ and %LOCALAPPDATA%\RightWheel\.

3. Microsoft Store Licensing

When installed via Microsoft Store, RightWheel uses the official Windows Store licensing API (Windows.Services.Store.StoreContext) solely to verify your trial or Pro Add-on entitlement. No third-party tracking SDKs are included.

4. Contact

For privacy questions or support, please contact the publisher via our GitHub repository: https://github.com/chautnus/RightWheel.
